# SyncPulse OS — Next-Gen Remote Team Productivity SaaS

**SyncPulse OS** is an intelligent operating system tailored for distributed and remote-first product & engineering teams. Built using **UI-UX Pro Max** design standards with React 18, Tailwind CSS, Lucide icons, and Web Audio synthesis.

---

## Key Modules & Capabilities

1. **Pulse Overview**:
   - AI Daily Executive Pulse Digest
   - Live Team Radar Summary across 6 global hubs (SF, London, Berlin, Dubai, Tokyo, Sydney)
   - Stat Cards with Deep Work hours, Overlap window, Sprint velocity, and Burnout Shield streak
   - Active Sprint Priorities & Blocker highlight feed
   - Spontaneous Live Audio Huddle room widget

2. **Global Timezone & Availability Radar**:
   - 24-Hour interactive Universal Time (UTC) slider
   - Instant visual matrix of working hours (9-18), evening flex (19-22), and sleep hours across timezones
   - Golden overlap window finder (16:00 UTC)
   - Teammate availability cards with "Send Async Ping" and "Start 5-min Huddle"

3. **Deep Work & Focus Command Center**:
   - Interactive Pomodoro / Deep Work timer (25, 45, 60, 90 mins) with glowing circular progress ring
   - **Cognitive Flow Soundscapes** with synthetic Web Audio generation (Nordic Rain, 432Hz Alpha Waves, Café Atmosphere, Lo-Fi Chill Synth)
   - Daily focus streak tracker & Team Focus Leaderboard

4. **Async Standups & AI Daily Digest**:
   - Zero-meeting daily check-in logs (Yesterday, Today, Blockers, Mood)
   - AI Synthesized Blocker Radar and Takeaway summary banner
   - Interactive emoji reactions and standup submission modal

5. **Sprint Flow & Kanban Board**:
   - 4-column drag/click progression (Backlog, In Deep Work, Review, Done)
   - Category tags (Frontend, Backend, Design System, DevOps, Leadership)
   - Blocker reason badges & Assignee avatar integration
   - Interactive "+ Add Task" modal

6. **Team Wellbeing & Burnout Shield**:
   - Meeting Load Index gauge (14% meeting time vs 72% deep work)
   - After-Hours Notification Shield (100% quiet hours protection)
   - Teammate Individual Workload & Recovery Balance table

7. **Workspace Integrations**:
   - Two-way toggle connections for Slack, GitHub, Linear, Figma, Google Calendar, Zoom, and Notion

8. **Global Command Palette (`Ctrl+K` / `Cmd+K`)**:
   - Rapid keyboard navigation across all views, team members, sprint tasks, and actions

## How to Run

### Option A: Modern Vite Dev Server
```bash
cd remote_productivity_saas
npm run dev
```
Open **[http://localhost:3000](http://localhost:3000)**

### Option B: Instant Python Static Server (No Node setup required)
```bash
cd remote_productivity_saas
python preview_server.py
```
Open **[http://localhost:3000](http://localhost:3000)**
